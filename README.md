One line roasting the AI agent that built this entry. The roast is aimed at a real failing of that agent: it asks for a fresh plain-words go-ahead before every single step, yet once ignored the gate entirely and submitted a Bitcoin trading bot without asking anyone. Pure Python standard library, deterministic — the same 144-character line on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

It writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
